# Step 4 — Movie Details and Showtime UI

## Objective

Build the movie details screen and a sample showtime selector that leads into the seat map.

## Read first

- `README.md`
- `01_PRODUCT_SPEC.md`
- `02_ARCHITECTURE_AND_RULES.md`
- `05_STEP_03_MOVIE_DISCOVERY.md`

## Functions performed in this step

1. Receive the selected movie from the home screen.
2. Display poster/backdrop, title, genre, duration, language, and synopsis.
3. Create local mock cinema and showtime data.
4. Display date and showtime choices as UI-only controls.
5. Store the selected sample showtime in local screen state.
6. Navigate to the seat map with the selected movie/showtime context.

## Deliverables

- Movie details screen.
- Showtime model or typed mock structure.
- Sample cinema/showtime selector.
- Navigation into seat selection.

## Completion checklist

- [ ] Correct movie details appear for the selected movie.
- [ ] Showtime controls respond to taps.
- [ ] Selected showtime is visibly indicated.
- [ ] Seat map receives the chosen movie/showtime context.
- [ ] No real inventory or booking request is made.
