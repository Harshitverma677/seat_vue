# Step 3 — Movie Discovery UI

## Objective

Build the home screen and movie browsing experience using local mock data.

## Read first

- `README.md`
- `01_PRODUCT_SPEC.md`
- `02_ARCHITECTURE_AND_RULES.md`
- `04_STEP_02_DESIGN_SYSTEM.md`

## Functions performed in this step

1. Define a typed `Movie` model.
2. Create a local list of sample movies.
3. Build the home screen layout.
4. Display featured content and movie cards.
5. Add basic category/filter chips if they appear in the reference design.
6. Add navigation from a movie card to its details screen.
7. Add empty or fallback poster handling.

## Mock data rules

Use local assets or placeholder images. Do not fetch live movie data. Keep sample data separate from widgets.

## Deliverables

- Home screen.
- Movie model.
- Local mock movie data.
- Movie-card widget.
- Navigation to movie details.

## Completion checklist

- [ ] Multiple sample movies render.
- [ ] Movie cards have consistent dimensions.
- [ ] Tapping a movie opens the correct details.
- [ ] UI works on different screen sizes.
