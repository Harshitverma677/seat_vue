# 🎬 SEAT VIEW

### Choose your seat. Experience the cinema in 3D.

A Flutter-based cinema seat selection app featuring an interactive 3D auditorium experience.
</div>

---

## ✨ Features

- 🎟️ **Seat Selection** – Select seats for your cinema experience
- 🪑 **3D Auditorium** – Explore a realistic 3D cinema environment
- 🎥 **Cinema Preview** – Preview your selected seats from an auditorium perspective
- 🔄 **Interactive Experience** – Visual interaction with the 3D seating environment
- 📱 **Cross-Platform UI** – Built with Flutter

---

## 🛠️ Tech Stack

| Area                | Tech                 |
| ------------------- | -------------------- |
| 📱 App              | Flutter, Dart        |
| 🎮 3D Visualization | Three.js, JavaScript |
| 🌐 Integration      | WebView Flutter      |
| 🔗 Networking       | HTTP, HTTP2          |
| 🚀 App Updates      | Shorebird            |

---

## 🧠 How It Works

```text
Flutter UI ➜ WebView ➜ Three.js ➜ 3D Cinema Experience
```

- Flutter handles the main application interface.
- WebView connects the Flutter app with the 3D experience.
- Three.js renders the cinema auditorium and seats.
- JavaScript handles the 3D scene interactions.

## ⚡ Getting Started

### 📱 Run the app

```bash
git clone https://github.com/Harshitverma677/seat_vue.git
cd seat_vue
flutter pub get
flutter run
```

### 📦 Build APK

```bash
flutter build apk --release
```
