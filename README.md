# Seat View

Seat View is a Flutter cinema seat-selection prototype with an immersive, seat-specific 3D auditorium preview.

This documentation package defines the requested UI, seat map, 3D scene, camera transitions, POV information sheet, and geometric seat metrics. It is an implementation specification, not evidence that these features already exist in the repository.

## Product scope

- Flutter app for Android and iOS.
- Mock cinema, hall, showtimes, seat inventory, prices, and booking confirmation.
- Interactive 9-row × 14-seat map.
- True 3D auditorium and selected-seat point of view.
- No authentication, live cinema inventory, backend, payment gateway, or real ticket issuance in this phase.
