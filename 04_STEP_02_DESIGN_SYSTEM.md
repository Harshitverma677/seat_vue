# Step 2 — Design System and Reusable UI

## Objective

Create the shared visual foundation so all screens look consistent with the reel's dark cinematic style.

## Read first

- `README.md`
- `01_PRODUCT_SPEC.md`
- `02_ARCHITECTURE_AND_RULES.md`

## Functions performed in this step

1. Define the color palette: background, surface, primary accent, selected seat, unavailable seat, and text colors.
2. Define typography styles and text hierarchy.
3. Define spacing, corner radii, and elevation/shadow conventions.
4. Create reusable buttons, chips, cards, section headers, and loading placeholders.
5. Configure the global Material theme.
6. Check contrast and touch-target sizes.

## Suggested reusable components

- `PrimaryButton`
- `MoviePosterCard`
- `SectionHeader`
- `AppBottomNavigation` (only if needed by the design)
- `StatusChip`
- `LoadingPlaceholder`

## Deliverables

- Centralized theme files.
- Reusable shared widgets.
- A temporary style-preview screen or sample page.

## Completion checklist

- [ ] Colors and text styles are centralized.
- [ ] Reusable components do not duplicate styling.
- [ ] Buttons and tappable controls have adequate touch targets.
- [ ] Dark theme is consistent across the app.
